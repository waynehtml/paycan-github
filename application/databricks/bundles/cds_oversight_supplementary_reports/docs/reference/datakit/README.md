# DataKit reference

DataForge vendors selected documentation from the DataKit Python project so
the supported shared-library contract remains available in a standalone
DataForge project.

DataKit retains the `oeds-common` distribution and `oeds.core` import namespace
for compatibility.

- Use the [generated API index](api/README.md) for the complete public inventory,
  exact signatures, and source docstrings.
- Use the [DataKit guides](guides/) for API selection, runtime assumptions,
  restrictions, side effects, and operational guidance.

Files under `api/` and `guides/` are synchronized source snapshots. Do not edit
them directly; use `/sync-references` when an explicit refresh is required.
